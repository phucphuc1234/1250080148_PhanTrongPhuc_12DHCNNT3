# Bài 7 — 7 sơ đồ trong một tab

Mở **Bai_7_7_So_Do_Mot_Tab_Gon.xml** bằng [diagrams.net (draw.io)](https://app.diagrams.net/): **File → Open From → Device**. File có đúng **một tab**, gồm bảy khung đánh số; phóng to khung cần xem.

1. Danh mục 25 lớp: đầy đủ thuộc tính, phương thức, ID.
2. Class Diagram có 43 quan hệ, chia cụm để dây ngắn và dễ đọc.
3. Use Case tổng quát theo nhóm nghiệp vụ.
4. Use Case phân rã quá trình thử việc đến ký hợp đồng.
5. Activity Diagram theo các vai trò.
6. Sequence Diagram lập quyết định khen thưởng.
7. Class chi tiết có quan hệ, gồm các hộp tham chiếu được ghi rõ.

Các hộp cùng tên biểu diễn **cùng một lớp**; lặp hộp tham chiếu để không kéo dây xuyên cụm. Dây quan hệ dùng các đoạn ngang/dọc, gấp khúc vuông góc. Sequence giữ lifeline dọc và thông điệp ngang theo UML.

Tất cả hình, chữ, đường nối đều là phần tử XML chỉnh sửa được. XML là định dạng draw.io, không phải StarUML `.mdj`. Thư mục `Xem_tung_khung` chứa ảnh của từng khung để xem nhanh.
